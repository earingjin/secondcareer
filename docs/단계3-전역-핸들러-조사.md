## 5. 조사의 한계

- 식별자 추출은 정규식 기반 토크나이저라 정규식 리터럴·중첩 템플릿에서 드물게 틀릴 수 있다.
- 테스트의 in-page 코드와 Node 쪽 코드를 영역 단위로 나눴으므로, 같은 이름의 Node 쪽 변수는 제외되지만 in-page 영역 안의 로컬 변수와 이름이 겹치면 "비고"에 표시한다.
- 호출 관계는 이름이 본문에 나타나는지로 판정하므로 문자열 속 같은 단어도 간선이 될 수 있다(과대 추정). 문자열로만 호출되는 핸들러는 포함된다.
