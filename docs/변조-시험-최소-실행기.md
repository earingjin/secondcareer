# 최소 변조 시험 실행기 (`tests/tools/min-mut.mjs`)

테스트 도구나 정답표 생성 방식이 바뀔 때, 테스트가 실제로 변조를 잡는지 **6건의 최소 표본**으로 확인한다. 범주당 1건 이하이고, 순수 이동 단계에서는 정답표 통과가 증거이므로 쓰지 않는다(`CLAUDE.md`).

> 이전에 만들었던 44건 스위트(`mutation-suite`)는 저장소에 넣지 않았다. 서버를 부모 프로세스 안에 두고 동기 `spawnSync`로 테스트를 돌려 서버가 막히는 결함이 있었다. 이 실행기는 비동기 `spawn`을 쓴다.

## 사용법
```powershell
node tests/tools/min-mut.mjs            # 6건 전부(약 35초)
node tests/tools/min-mut.mjs 1          # 1번만(약 5초)
node tests/tools/min-mut.mjs 2,3,4      # 골라서
node tests/tools/min-mut.mjs --list     # 변형 목록
npm run test:minmut                     # 6건 전부
```
- 저장소 파일은 건드리지 않는다. `legacy/index.original.html`의 복사본에만 변조를 적용하고, 임시 폴더(`%TEMP%\sp-min`)를 정적 서버로 서빙해 `TARGET_URL`로 지정 테스트만 실행한다. 끝나면 서버와 임시 폴더를 정리한다.
- 변형마다 **3분 제한**, **첫 실패 시 중단**(`--max-failures=1`), **테스트당 60초**. 시간이 오래 걸리면(첫 변형이 2분을 넘으면) 중단하고 원인을 찾는다.

## 변형 6건
| # | 변조(원본에서 바꾸는 곳) | 지정 테스트 | 잡혀야 하는 이유 |
|---|---|---|---|
| 1 | 판정 구간 `cut:[[7,10,13]` → `[[8,10,13]` | `golden.spec` `환산·판정` | 판정 경계가 정답표와 달라짐 |
| 2 | 문항 문구 `A3:'귀하의 성함을…'` → `'귀하의 이름을…'` | `contract.spec` `문항 정의 덤프` | 문항 정의 정답표가 달라짐 |
| 3 | 로그인 제목 `<h2>진단 시작하기</h2>` → `…하기!</h2>` | `snapshot.spec` `p-login`(`SCENE=^p-login$`) | 화면 HTML 기준선이 달라짐 |
| 4 | CSS `--coral:#2F7C82;` → `#2F7C83;` | `snapshot.spec` `CSS 규칙 지문` | CSS 규칙 지문이 달라짐 |
| 5 | 수정 잠금 `if(!post&&isSubmitted(p)&&!S.cedit)return` → `if(false)return` | `roles.spec` 3단계 `제출 후 결과가 보이지 않고 수정이 잠긴다` | 제출 후에도 마법사가 열림. 흐름 시험이라 1·2단계가 선행 조건으로 함께 실행됨 |
| 6 | (변조 없음) 1번과 같은 테스트를 **원본 서버**에 실행 | `golden.spec` `환산·판정` | 변조 서버(1번)에서는 실패하고 원본 서버에서는 통과해야 `TARGET_URL`이 대상을 정확히 가리킨다는 증거 |

## 판정 5종
| 판정 | 뜻 | 합격? |
|---|---|---|
| 잡힘 | 지정한 테스트가 실패함 | 합격 |
| 다른 테스트가 잡음 | 지정 테스트는 아니지만 다른 테스트가 실패함 | 합격 아님(지정 테스트가 변조를 못 본 것 — 원인 확인) |
| 안 잡힘 | 지정 테스트가 통과함 | 불합격 |
| 시간 초과 | 3분 제한 초과 | 불합격(합격으로 세지 않음) |
| 오류 | 변조 대상 문자열 불일치, 결과 파일 없음, 실행된 테스트 없음 등 | 불합격(합격으로 세지 않음) |

6번은 "원본 서버 통과"와 1번의 "잡힘"이 모두 맞을 때만 잡힘이다.

## 주의(실제로 겪은 것)
- 테스트 선택(`-g`) 패턴에 **백슬래시를 쓰지 않는다.** 셸을 거치며 깨져 테스트가 하나도 선택되지 않아 "오류"가 났다(5번에서 겪음). 제목의 고유한 한글 구절을 `|`로 이어 쓴다.
- 변조할 문자열은 원본에서 **정확히 한 번** 나타나야 한다. 아니면 "오류"로 끝난다. 원본이 바뀌면 `tests/tools/min-mut.mjs` 상단의 `V` 정의를 고친다.
- 대상이 `legacy`이므로 `src` 전용 변조(데이터 파일·정의 파일)는 이 6건에 없다. 필요하면 변형을 추가하되 범주당 1건 이하로 한다.
